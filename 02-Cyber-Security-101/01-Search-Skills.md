# TryHackMe: Search Skills

## 📅 التاريخ
2026-09-20

## 🎯 الهدف
تعلم كيفية البحث بفعالية عن المعلومات الأمنية باستخدام محركات البحث المتخصصة.

## 🧠 المفاهيم التي تعلمتها
- تقييم مصداقية المصادر (4 معايير: المصدر، الأدلة، الموضوعية، التأكيد).
- Search Operators: `""`, `site:`, `-`, `filetype:`.
- محركات بحث متخصصة: Shodan, Censys, VirusTotal, Have I Been Pwned.
- قواعد بيانات الثغرات: CVE, Exploit Database, NVD.
- صفحات الدليل (Man Pages) ووثائق المنتجات.
- OSINT عبر وسائل التواصل الاجتماعي (LinkedIn, Facebook).

## 🛠️ الأدوات التي استخدمتها
| الأداة | الوظيفة |
| :--- | :--- |
| Shodan | البحث عن أجهزة متصلة بالإنترنت |
| VirusTotal | فحص الملفات والروابط |
| CVE MITRE | البحث عن الثغرات |
| Have I Been Pwned | التحقق من تسريب البريد |

## 🔬 الخطوات العملية
1. استخدمت Shodan للبحث عن أجهزة بـ TryScanMe.
2. فحصت ملفاً مشبوهاً في VirusTotal.
3. بحثت عن ثغرة CVE-2024-3094 في قاعدة بيانات CVE.
4. استخدمت `man` لفهم أوامر Linux.
5. بحثت في GitHub عن أدوات مفتوحة المصدر.

## 💡 ماذا تعلمت
- البحث الفعال مهارة أمنية حرجة.
- معرفة أين تبحث لا تقل أهمية عن ماذا تبحث.
- المصادر الموثوقة أساس أي تحليل أمني.
