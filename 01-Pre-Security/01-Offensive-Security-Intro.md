# TryHackMe: Offensive Security Intro

## 📅 التاريخ
2026-09-20

## 🎯 الهدف
تعلم أساسيات الأمن الهجومي وتطبيق أول اختبار اختراق.

## 🧠 المفاهيم التي تعلمتها
- الأمن الهجومي: محاكاة هجمات المخترقين بشكل قانوني.
- التعداد (Enumeration): البحث عن صفحات مخفية.
- Broken Access Control: الوصول لصفحات بدون تصريح.

## 🛠️ الأدوات التي استخدمتها
| الأداة | الوظيفة |
| :--- | :--- |
| Gobuster | اكتشاف المجلدات والصفحات المخفية |

## 🔬 الخطوات العملية
1. شغلت الأمر: `gobuster -u http://fakebank.thm -w wordlist.txt dir`
2. وجدت الصفحة المخفية: `/bank-transfer`
3. استغليت الثغرة وحولت 2000$ من حساب 2276 إلى 8881.
4. حصلت على العلم: `BANK-HACKED`

## 💡 ماذا تعلمت
- التفكير كمهاجم يكشف ثغرات لا يراها المطورون.
