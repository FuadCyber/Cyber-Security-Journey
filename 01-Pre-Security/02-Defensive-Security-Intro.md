# TryHackMe: Defensive Security Intro

## 📅 التاريخ
2026-09-20

## 🎯 الهدف
فهم الأمن الدفاعي (Blue Team) وكيفية حماية الأنظمة واكتشاف الهجمات.

## 🧠 المفاهيم التي تعلمتها
- الأمن الدفاعي: حماية + كشف + استجابة.
- SOC: غرفة تحكم تراقب الشبكة 24/7.
- SIEM: نظام يجمع السجلات ويحللها.
- Threat Intelligence: معلومات عن المهاجمين.
- DFIR: التحقيق الجنائي الرقمي والاستجابة للحوادث.
- Malware Analysis: التحليل الثابت والديناميكي.

## 🛠️ الأدوات التي استخدمتها
| الأداة | الوظيفة |
| :--- | :--- |
| SIEM Dashboard | مراقبة التنبيهات الأمنية |
| IP Blocklist | حظر عنوان IP المهاجم |

## 🔬 الخطوات العملية
1. فتحت لوحة المراقبة (SIEM Dashboard).
2. اكتشفت IP المهاجم: `32.122.195.63`.
3. حددت هدف المهاجم: `https://fakebank.com/admin`.
4. أضفت IP إلى قائمة الحظر.
5. حصلت على العلم: `THM{FAKEBANK-SECURED}`.

## 💡 ماذا تعلمت
- الأمن الدفاعي يتطلب مراقبة مستمرة واستجابة سريعة.
- SIEM هو "رادار" الأمن السيبراني.
